01 / SWIFTAPPLE PLATFORMS

KaiwaKit for Swift

Native audio capture and AI playback for Apple apps. Install with Swift Package Manager.

.package(
  url: "https://github.com/shogo4405/KaiwaKit",
  from: "{{VERSION}}"
)

02 / KOTLINANDROID

KaiwaKit for Android

Native Kotlin APIs for Android voice applications. Add the JitPack repository, then the SDK.

// settings.gradle.kts · repositories
maven { url = uri("https://jitpack.io") }
// app/build.gradle.kts · dependencies
implementation("com.github.shogo4405:KaiwaKit:{{VERSION}}")
